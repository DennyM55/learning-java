The statement that "Each thread must be contained in a separate executable (exe)" is not true for threads. Threads are typically contained within a single executable and can share the same process space. Here's the rationale for each statement:

2. "Threads share heap area, files, and memory." - This is true. In a multithreaded process, threads share the process's resources such as the heap, open files, and other memory resources.

3. "Every thread has a separate program counter, local variables, and stack area." - This is true. Each thread maintains its own program counter, stack, and local variables, which are separate from other threads to enable concurrent execution without interference.

4. "Threads allow for multiple activities within a process." - This is true. The main advantage of threads is that they allow multiple activities to be carried out simultaneously within the same process.
