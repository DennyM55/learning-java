Question:
What will be expected when the following snippet executes?

java
Copy code
public class MyDemo {

    public static void main(String[] args) throws Exception{

        Thread.sleep(3000);

        System.out.println("sleep");

    }

}
Options:
A) Compilation fails.
B) An exception is thrown at runtime.
C) The code executes normally and prints "sleep".
D) The code executes normally, but nothing is printed.

Answer:
The code executes normally and prints "sleep". The main method uses Thread.sleep(3000); to pause the execution of the thread for 3000 milliseconds. After the sleep period, it proceeds to print "sleep" to the console. The main method also declares that it throws Exception, which covers the InterruptedException that Thread.sleep() might throw. There is no compilation error, and assuming the environment is set up correctly, no exception will be thrown at runtime. The correct option is C) The code executes normally and prints
