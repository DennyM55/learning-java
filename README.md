# learning-java

This Maven project is a Java learning workspace. It contains general Java practice code under `org.example.streams` and `org.example.threads`, plus an interview-preparation knowledge area under `org.example.interview`.

The interview area is organized by technical concept rather than by company. Each `qXXX` folder is a stable question ID with a self-contained `README.md`. Some questions also include a small runnable Java example when code makes the concept easier to understand.

Build and test with:

```text
mvn test
```
